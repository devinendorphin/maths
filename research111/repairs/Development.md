# Development gates before the repair headline run

The repair is a supplement to preserved A/C evidence, not a renumbering or rerun of either campaign. Protocol.json was written before new installation/experimental execution. The completion-setup amendment was recorded before the headline freeze.

Signed Debian metadata recovered MPFR and Boost. SoPlex 8.0.0 and SCIP 10.0.0 built with exact support in 320.28 seconds in the timed setup script. The earlier missing-MPFR conclusion was only a failed configuration attempt. Source inspection independently establishes that exact SCIP 10 and reoptimization are incompatible; ordinary reoptimization is a separate supported path.

The fork wrapper initially failed compilation for a missing standard `<iomanip>` include, corrected before the headline freeze. The PySCIPOpt documentation labels reoptimization's objective input as a list, but its actual API requires an expression; a two-variable development probe exposed this and the repair uses an expression. Neither failed development probe contributes headline outcomes.

SCIP's native certificate on the crossing control passed the unchanged inherited checker. The larger factor fixture contained `lin weak` derivations even with separating/maxrounds and separating/maxroundsroot zero. Official VIPR completion was therefore added. Upstream TBB's old CMake minimum failed under CMake 4.4; a compatible CMake 3.31.6 installation built the unedited official VIPR tools in an additional timed 93.05-second setup, within its separately declared 180-second cap. Source/checksum/TLS verification remained enabled. The completion output was accepted by the unchanged inherited VIPR checker.

SCIP may normalize the objective by a positive common factor and convert maximize to minimize. The independent auditor checks both algebraic mappings, all original variable/integrality/bound/capacity constraints, and the recorded objective against original-model enumeration. Disabling presolve does not eliminate this objective normalization, which is explicitly checked rather than assumed absent.

The original development files and logs are retained in the repair archive. SDK sources/installations remain outside Git. Neither fresh experimental replication nor use of a different checker process is an independent SDK installation.
