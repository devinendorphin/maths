# Full cost accounting: executed, checked and replicated, 156–159

The larger changing-allocation inquiry now has an exhaustive elapsed-time ledger
for its existing specialist workload. The old 152 timers left about 53% of the
largest warm query time outside named phases. New exclusive intervals account
for copying, model checks, encoding, native calls, proof work, recording and
observer bookkeeping without adding nested time twice. This is an accounting
study of the known 152 inputs, not a fresh held-out performance claim.

Each accepted directory completed 144 fresh processes and 7,056 certified
observations: six networks, six routes, two repetitions and two observer modes,
with 49 queries per process. Each audit checked 294 model outcomes against
NetworkX and SimpleMinCostFlow, admitted 627 distinct proofs, replayed native
state and checked 2,016 shortage cuts. All scientific records and raw journal
bytes match exactly across modes, repetitions and the two directories. The
combined accepted headline count is 14,112; the 3,528-observation development
run is separately labelled and excluded. All 1,256 predecessor files remain
unchanged, including every scientific archive, source freeze and publication seal.

Every one of the 7,056 observed headline query ledgers sums exactly to its
enclosing query clock; all 144 observed worker ledgers sum exactly to their
worker clocks. The independent verifier also checks 1,764 excluded development
query ledgers. Twelve corrupted-ledger controls are rejected, and all 42 inherited
transaction/native controls pass with the observer installed. Full interval
endpoints and full mathematical/native/witness records are retained.

The accepted source freeze follows a recording repair. The first primary run
completed 144 workers, but its audit found two visible journals containing only
25/26 of the declared 49 records. Cause is not established; complete Worker.json
records do not excuse missing raw bytes. The entire rejected run and original
development/source root are preserved and excluded. No journal was reconstructed.
The repaired path streams to an anonymous temporary file, checks all bytes/records,
then atomically publishes and reads back each complete journal. Worker/Accounting
JSON also receive atomic complete writes/readback. Development and both headline
directories reran under a fresh source freeze; no accepted worker or ledger failed.
This changes measured recording work in both modes and does not claim power-loss
durability or an externally attested clock.

The three largest categories—transaction copying, validation and encoding—use
about 67.3%/66.6% of observed warm query time. Native create/patch/solve/snapshot
calls together use about 3.6% in both runs. This redirects the next experiment
toward representation/copy/check costs. It does not assign all validation or
encoding to the native interface: those global categories include transaction,
native-input and proof checks at the named source boundaries. The solve category
includes C++ witness admission, and categories are costs of the observed program.

Costs beyond the query remain explicit. Warm worker ledgers total 855.2/850.7 ms;
imports use 116.7/117.5 ms and source/native provenance hashing 75.5/77.6 ms.
Record ownership uses 35.1/33.1 ms; final Worker JSON encoding 49.9/48.2 ms;
closed-journal publication/checking 12.4/11.9 ms. Complete parent process clocks
are 898.2/893.8 ms. Parent-minus-worker gaps of 43.0/43.1 ms include final timing
receipt writing/readback, initial interpreter bootstrap, shutdown, scheduling
and polling. They are not silently assigned to startup or proof work. Source
boundaries and raw category totals are in [Results.json](Results.json).

The observer comparison is deliberately not a subtraction-based correction.
Warm complete-process medians are 898.2 vs 832.4 ms observed/unobserved in primary,
893.8 vs 930.3 in replica. Across all cells observer-on/off complete ratios range
from 0.889 to 1.140. Faster observed cells demonstrate run variability, not
negative causal instrumentation cost. Sampled observer intervals (2.4/2.6 ms
inside these warm queries) exclude some wrapper/context/clock instructions that
land in adjacent intervals. Paired clock-read calibration is retained; no
component is adjusted into a fictitious unobserved timing. Two repetitions cannot
support significance estimates for small gaps or a new general solver ranking.

The accounting question is closed within this contract: no query time is left
as an unlabelled arithmetic remainder, and the process envelope gap is explicitly
charged. Coarse local control categories remain honest about their boundaries.
The next [roadmap](Roadmap.md) is a bounded representation and ownership experiment
preserving atomic updates, caller isolation, exact proof admission and full state
replay. Wider topology, literature-priority, authenticated-update and consenting
application questions remain open. No real allocation or policy legitimacy is
established by these synthetic timings.
