# Allocation roadmap: experiments 133–136

The four bounded stages in the [allocation charter](../projects/certified-allocation/Problem.md)
have been executed on synthetic inputs. Read [Synthesis.md](Synthesis.md),
[Alignment.md](Alignment.md), [Assurance-contract.md](Assurance-contract.md),
[Maintenance-bound.md](Maintenance-bound.md) and [REPRODUCE.md](REPRODUCE.md).

Per directory: 232 isolated workers, 2,099 audited query/probe records, four held-out
base networks (4–10 nodes, 4–25 edges), 11 static fixtures, eight service-policy
cases, and one designed counterexample. The 227 distinct certificates comprise
145 optimality proofs and 82 infeasibility cuts. All 1,488 invalid controls are
rejected. Three timing repetitions are separate from the number of mathematical
models. Every mathematical record, proof identity and operation count matches
fresh-directory replication. Ten separately frozen assurance groups also match.

These results establish a working bounded pipeline, not a general performance
advantage, formal verification, independent SDK installation or real allocation
deployment. Earlier evidence and its counts remain unchanged. The preliminary
JavaScript checks during the environment outage are not counted here.
